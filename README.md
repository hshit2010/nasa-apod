## ✨ Features

- **🎥 Dynamic Media Handling:** Seamlessly transitions between high-resolution images and embedded videos based on NASA's daily payload.
- **🪞 Glassmorphism UI:** A sleek, frosted-glass interface that floats effortlessly over a dark cosmic background.
- **⚡ Cyberpunk Aesthetics:** Neon glowing typography, particle-like hover states, and smooth CSS micro-interactions.

## 🛠️ Tech Stack

Built with lightweight, vanilla technologies for maximum performance and a smooth developer experience.

- `HTML5` - Semantic structure
- `Vanilla JavaScript (ES6+)` - Core logic, API fetching, and DOM manipulation
- `Custom CSS3` - CSS Variables, Flexbox, Keyframes, and Backdrop Filters
- `Vite` - Next-generation frontend tooling for instantaneous hot-module replacement (HMR)
- `GitHub Actions` - CI/CD for automated deployment to GitHub Pages

## 🚀 Quick Start

Want to run this locally? Follow these steps to get the cosmos booting on your machine.

**1. Clone the repository**
```bash
git clone [https://github.com/hshit2010/nasa-apod.git](https://github.com/hshit2010/nasa-apod.git)

2. Navigate to the project directory
Bash

cd nasa-apod

3. Install dependencies
Bash

npm install

4. Set up your Environment Variables
Create a file named .env in the root of your project and add your own free API key from api.nasa.gov:
Plaintext

VITE_NASA_API_KEY=your_api_key_here

5. Boot the Vite dev server
Bash

npm run dev
